# Data Model: 可靠点击与点击落光标

**Date**: 2026-11-25
**Feature**: [spec.md](./spec.md)

本特性不引入持久化数据；下面是编辑器运行期的核心实体、它们的不变量与状态迁移。
实现以现有模块内变量承载，不新增存储或全局框架。

## 实体

### 编辑会话（EditingSession）

任一时刻至多存在一个。三种形态互斥：

| 形态 | 触发 | 关键字段 |
|------|------|----------|
| 块级 `BlockSession` | 点击/键盘导航/格式命令进入某文本块 | 块标识 `cid` |
| 单元格 `CellSession` | 点击单元格、Tab/Enter 导航、菜单命令 | 表块标识 `cid`、行 `r`、列 `c`、单元格元素引用 |
| 代码 `CmSession` | 点击代码块/公式块 | 块标识、种类、基线源码 |

**不变量（规格 FR-012）**：会话存在 ⇔ 其对应元素在文档中、可编辑、是当前焦点元素，且光标或选区位于其内。

**内容来源**：会话期间用户输入活在 DOM 里；已提交的源码存在块对象的 `source` 字段。
提交 = 把 DOM 文本写回 `source` 并重渲染。任何提交、清除、修复都必须先读取 DOM 文本（FR-015）。

**校验规则**：
- 会话登记在聚焦之前完成（先登记、后聚焦），避免聚焦过程中派发的焦点事件看到半成品状态。
- 所有延时回调必须按"登记时的标识"校验，标识已变即放弃。
- 每次鼠标按下处理之前执行一致性校验：不满足不变量的会话先提交再清除（FR-013）。

### 状态迁移

```text
                 点击渲染态块 / 空白区 / 键盘跨界
   (无) ─────────────────────────────────────────▶ BlockSession
     │                                                   │
     │ 点击单元格（Tab/Enter/Delete 进入表格）              │ 点击单元格
     ▼                                                   ▼
   CellSession ◀─────────────────────────────────── (经提交回到"无"后进入)
     │
     │ 点击代码块/公式块
     ▼
   CmSession

   任一形态 ──提交（Esc、焦点移出编辑区、切换目标、一致性修复）──▶ (无)
```

**迁移规则**：一次迁移在一个同步任务内按固定顺序完成——
`一致性校验 → 提交当前会话 → 定位新目标 → 登记新会话 → 聚焦并放置光标`。
禁止把"提交旧会话"寄托在之后才触发的焦点事件或定时器上。

### 按下手势（PressGesture）

用户在渲染态块上按下鼠标时创建，服务于拖选与双击，鼠标松开或超时后失效。

| 字段 | 含义 |
|------|------|
| `cid` | 被按下的块 |
| `startedAt` | 按下时间（判定双击窗口） |
| `anchor` | 源码态里的锚点（节点、偏移） |
| `lineMap` | 被按下那一行的落点映射（见下），供双击选词换算 |
| `lineText` | 该行渲染态可见文字 |
| `dragging` | 是否处于按住拖动中 |

**校验规则**：仅当首次按下使块进入编辑态时创建；块原本就在编辑态则不创建（交给原生手势）。
双击窗口之外或换了块，手势作废。

### 落点映射（CaretMap）

针对某一块的某一行：

| 字段 | 含义 |
|------|------|
| `visible` | 该行渲染后的可见文字（与真实渲染结果逐字一致） |
| `toSrc[i]` | 第 i 个可见字符在源码中的起始下标（相对该行正文） |
| `prefixLen` | 该行不可见的块级前缀长度（`# `、`- `、`> `、任务框等） |
| `lineStart` | 该行在块源码中的起始下标 |

**校验规则**：`toSrc` 必须严格单调递增且覆盖全部可见字符；不满足即映射失败。
换算：可见边界 v → 源码偏移 `lineStart + prefixLen + toSrc[v]`；
当 v 两侧可见字符之间夹着不可见语法时，按点击落在前一个字符的后半还是后一个字符的前半取舍。

### 诊断记录（TraceEntry / DiagReport）

- `TraceEntry`：`{ t, ev, cid?, cell?, off?, active? }`，环形缓冲，容量 80，只记录编辑器状态切换与焦点变化，不记录正文内容。
- `DiagReport`：`{ app, now, state, active, caretIn, issues[], trace[] }`；`issues` 为导出时刻的一致性检查结果。
